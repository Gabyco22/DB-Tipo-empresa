# DB-Tipo-empresa
ESPAÑOL:
Sistema de Gestion Empresarial Simple (Python + SQLite)

Este proyecto simula una empresa con sus departamentos, empleados y proyectos, utilizando Python y SQLite. Incluye consultas de salarios, asignaciones a empleados y logica de negocios.

Las principales caracteristicas de este proyecto son :
- Creación de tablas con claves foráneas.
- Inserción de datos iniciales.
- Consultas SQL con subqueries y joins.
- Actualización y eliminacion de registros.

Cómo ejecutar el proyecto
- Clonar el repositorio.
- Ejecutar python Empresa.py.
- Ver resultados en consola.

ENGLISH:
Simple Business Management System (Python + SQLite)

This project simulates a company with its departments, employees, and projects, using Python and SQLite. It includes salary queries, employee assignments, and business logic.

The main features of this project are:

Creating tables with foreign keys.
Inserting initial data.
SQL queries with subqueries and joins.
Updating and deleting records.

How to run the project:

Clone the repository.

Run the Python file Empresa.py.

View the results in the console.
